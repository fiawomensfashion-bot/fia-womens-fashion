FIA — PRODUCT PHOTOS
====================

Put all product photos in this folder.

Before uploading a photo:
  • Resize it to about 1000 px wide.
  • Keep each file under 300 KB (save as JPG, quality around 80%).
  • A portrait shape (4:5, for example 1000 × 1250 px) looks best on the cards.

File names:
  • Use lowercase letters, numbers and dashes only, no spaces.
    Good:  kurti-rose-1.jpg     Not good:  Kurti Rose (1).JPG
  • Type the name in products.js exactly as it is written here,
    for example:  images: ["kurti-rose-1.jpg", "kurti-rose-2.jpg"]

If a photo is missing or the name is mistyped, the website shows a soft pink
placeholder with the product's first letter instead of a broken image.

Free tools for resizing: squoosh.app (in the browser) or your phone's photo editor.
